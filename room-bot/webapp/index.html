⏰ زمان‌بندی دقیق

تلگرام خودش ربات رو سر ساعت بیدار نمی‌کنه؛ یه سرویس رایگان دقیقه‌ای یه بار ربات رو صدا می‌زنه تا پست‌های زمان‌بندی‌شده و قرعه‌کشی‌ها دقیق سر وقت انجام بشن.

در حال بررسی…
  1. برو به cron-job.org و رایگان ثبت‌نام کن.
  2. CREATE CRONJOB رو بزن. تو قسمت URL اینو بذار:
  3. زمان اجرا: Every 1 minute (هر دقیقه).
  4. تب ADVANCED: Request method رو POST کن، و تو Headers دو تا اضافه کن:
    Content-Type: application/json
    اسم هدر: Authorization — مقدارش همینیه که کپی کردی.
    تو Request body هم بنویس: {}
  5. CREATE رو بزن. یه دقیقه بعد بالای این صفحه سبز میشه ✅
⚠️ مقدار Authorization رو به کسی نده.
