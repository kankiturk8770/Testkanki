# ربات موزیک تلگرام + مینی‌اپ پلیر

ربات تلگرام برای پیدا کردن، تشخیص دادن، دانلود و ویرایش آهنگ و ویدیو، به‌همراه یک **مینی‌اپ** که پلیر کامل، پلی‌لیست، تاریخچه، برش‌زن و شناسایی زنده («گوش بده» مثل شازم) داره.

## امکانات

**در چت ربات**
- 🔎 جستجو با اسم آهنگ، خواننده یا یه تیکه از متن، هم‌زمان در **یوتیوب و ساندکلاد** (آهنگ‌های محلی، ریمیکس، کاور و لایو هم پیدا میشن). اگه یه منبع قفل یا حذف شده باشه، همون آهنگ رو خودکار از منبع دیگه می‌گیره.
- 🎙 **تشخیص آهنگ** از ویس، فایل صوتی، ویدیو، ویدیو مسیج یا **لینک** (اینستاگرام، تیک‌تاک، یوتیوب و ~۱۸۰۰ سایت دیگه).
  - ترتیب: Shazam ← AudD ← ACRCloud ← تشخیص **زمزمه** (ACRCloud Humming) ← **متن آوازی که کاربر می‌خونه** (Whisper) ← جستجوی متن آهنگ (Genius) ← جستجوی عادی
  - اگه کپشن ویس «زمزمه» باشه، مستقیم میره سراغ تشخیص زمزمه/آواز.
- 🎧 دریافت آهنگ با کیفیت **128 / 192 / 320** یا به‌صورت ویس؛ 🎬 ویدیو با کیفیت **360p تا 1080p**.
- 💬 دستور با متن: «آهنگشو بفرست»، «ویدیوشو بفرست»، «ریمیکساش»، «برش ۰:۳۰ تا ۱:۰۰»، «آهنگ بارون رو بفرست».
- ✂️ زیر هر آهنگ ارسالی: **برش**، **رینگتون** (mp3 اندروید / m4r آیفون)، **اسلو + ریورب**، **تند**، **باس بوست**، **8D**، **بی‌کلام (کارائوکه)**، **بلندتر**، ریمیکس‌ها، ویدیو.
- 🔁 پیدا کردن **ریمیکس‌ها و نسخه‌های دیگه** هر آهنگ.
- ❤️ لایک و ➕ اضافه کردن به پلی‌لیست از همون چت.
- ⚡ فایل‌هایی که یه بار فرستاده شدن با `file_id` کش میشن و دفعه بعد آنی ارسال میشن.

**در مینی‌اپ** (دکمه منوی ربات «🎵 پلیر»)
- 🎵 پلیر کامل: پخش/توقف، **کشیدن نوار** برای جلو/عقب، ±۱۰ ثانیه، سرعت پخش، قبلی/بعدی، **کشیدن کاور به چپ/راست** برای آهنگ بعد/قبل، **تکرار همه / تکرار یکی**، **تصادفی**، صف پخش، کنترل از صفحه قفل گوشی.
- ✂️ **برش زنده**: انتخاب شروع/پایان با اسلایدر یا «از همین لحظه»، **پیش‌نمایش تکراری همون بخش**، فید، و **دانلود** (mp3 / m4r رینگتون آیفون / ویس) یا ارسال به چت.
- 🎙 **گوش بده**: ضبط از میکروفون (۱۲ ثانیه) و تشخیص؛ حالت «خودم می‌خونم/زمزمه» و انتخاب فایل.
- 📚 کتابخانه:
  - **🌟 منتخب تو** — پلی‌لیست خودکار: از روی پخش، دانلود، ویرایش و لایک‌ها امتیاز می‌گیره (با کاهش امتیاز برای کارهای قدیمی) و بهترین‌ها رو جدا می‌کنه.
  - ❤️ لایک‌ها و 📁 پلی‌لیست‌های شخصی (ساخت، تغییر نام، حذف، حذف آهنگ).
- 🕘 **تاریخچه کامل** جدا از پلی‌لیست‌ها، روزبه‌روز، با فیلتر (جستجو، تشخیص، پخش، دانلود، ویرایش).
- 📩 ارسال آهنگ/ویدیو/افکت به چت مستقیم از پلیر.

## ساختار

```
music-bot/
├── bot/
│   ├── main.py        # یک سرور aiohttp: وب‌هوک تلگرام + مینی‌اپ + API
│   ├── handlers.py    # پیام‌ها و دکمه‌های چت
│   ├── webapi.py      # API مینی‌اپ (احراز هویت با initData تلگرام)
│   ├── sources.py     # جستجو/دانلود با yt-dlp (+ جایگزین خودکار)
│   ├── recognize.py   # Shazam, AudD, ACRCloud, Humming, Whisper, Genius
│   ├── audio.py       # ffmpeg: برش، افکت‌ها، رینگتون
│   ├── delivery.py    # ارسال فایل‌ها و کش file_id
│   ├── db.py          # SQLite: کاربر، تاریخچه، پلی‌لیست، لایک، منتخب
│   └── keyboards.py
├── webapp/            # مینی‌اپ (HTML/CSS/JS بدون فریمورک)
├── Dockerfile
└── .env.example
```

## APIها و کلیدها

| سرویس | برای چی | لازمه؟ | از کجا |
|---|---|---|---|
| **BotFather** | توکن ربات | ✅ | `@BotFather` ← `/newbot` |
| **Shazam** (shazamio) | تشخیص آهنگ | بدون کلید | — |
| **yt-dlp** | جستجو/دانلود یوتیوب، ساندکلاد، اینستا، تیک‌تاک… | بدون کلید | — |
| **AudD** | تشخیص؛ آهنگ‌های محلی/کمتر شناخته | اختیاری (پیشنهادی) | audd.io |
| **ACRCloud** (Music) | تشخیص؛ ریمیکس/کاور | اختیاری | console.acrcloud.com ← پروژه Audio & Video Recognition |
| **ACRCloud** (Humming) | تشخیص با **زمزمه/آواز** | اختیاری (پیشنهادی) | همونجا، یه پروژه جدا با bucket «Humming» |
| **Groq** یا **OpenAI** Whisper | تبدیل آواز کاربر به متن | اختیاری (پیشنهادی) | console.groq.com (رایگان) یا platform.openai.com |
| **Genius** | پیدا کردن آهنگ از روی متن | اختیاری | genius.com/api-clients |

بدون کلیدهای اختیاری هم ربات کار می‌کنه (Shazam + جستجو)؛ با هر کلیدی که اضافه کنی، تشخیص قوی‌تر میشه.

## راه‌اندازی روی سرورلس

ربات برای پردازش صدا به **ffmpeg** و **yt-dlp** نیاز داره، پس باید روی سرورلسی اجرا بشه که **کانتینر Docker** قبول می‌کنه (مثل Google Cloud Run، Fly.io، Railway، Render، Koyeb یا پلتفرم‌های ایرانی مثل لیارا و هم‌روش). پلتفرم‌های فقط-تابعی مثل Cloudflare Workers یا Vercel Functions برای این کار مناسب نیستن.

1. **ساخت ربات:** در `@BotFather` ← `/newbot` ← توکن رو بردار.
2. **دیپلوی:** پوشه `music-bot` رو به‌عنوان اپ Docker دیپلوی کن (Dockerfile آماده‌ست، پورت `8080`).
3. **متغیرهای محیطی** (از `.env.example`):
   - `BOT_TOKEN` — توکن ربات
   - `PUBLIC_URL` — آدرس https که پلتفرم بهت داده (مثلاً `https://mybot.example.app`)
   - `WEBHOOK_SECRET` — یه رشته تصادفی
   - کلیدهای اختیاری بالا
4. **دیسک دائمی:** یه Volume روی `/data` وصل کن (دیتابیس پلی‌لیست‌ها و تاریخچه اینجاست). بدون Volume، با هر ری‌استارت داده‌ها پاک میشن.
5. **تنظیمات پیشنهادی سرورلس:** حداقل ۱ نمونه همیشه روشن (min instances = 1) تا وب‌هوک‌ها سرد نشن، حافظه ≥ 1GB، timeout درخواست ≥ 300 ثانیه، و حداکثر ۱ نمونه (چون SQLite روی یه دیسکه).
6. با بالا اومدن سرویس، ربات خودش **وب‌هوک**، **دکمه منوی مینی‌اپ** و **دستورات** رو ست می‌کنه. آدرس مینی‌اپ: `PUBLIC_URL/app/`
7. (اختیاری) در BotFather: `/newapp` تا مینی‌اپ لینک مستقیم `t.me/YourBot/app` هم داشته باشه؛ URL رو `PUBLIC_URL/app/` بده.

### اجرا روی کامپیوتر خودت (تست)

```bash
cd music-bot
pip install -r requirements.txt     # ffmpeg هم باید نصب باشه
cp .env.example .env                # BOT_TOKEN رو پر کن، MODE=polling
set -a; . ./.env; set +a
python -m bot.main
```
در حالت polling ربات بدون آدرس عمومی کار می‌کنه؛ برای مینی‌اپ یه تونل https (مثلاً cloudflared) به پورت 8080 بزن و آدرسش رو در `PUBLIC_URL` بذار.

## محدودیت‌ها و نکته‌ها

- **حجم آپلود:** Bot API ابری تا **۵۰ مگ** آپلود و **۲۰ مگ** دانلود اجازه میده. ربات آهنگ‌های بزرگ رو خودکار با کیفیت پایین‌تر می‌فرسته؛ برای ویدیوهای بزرگ کیفیت پایین‌تر رو پیشنهاد میده. با [Local Bot API Server](https://github.com/tdlib/telegram-bot-api) می‌شه تا ۲ گیگ رفت (`MAX_UPLOAD_MB`).
- **یوتیوب و IP دیتاسنتر:** یوتیوب گاهی به IP سرورها «Sign in to confirm you're not a bot» میده. در این حالت ربات از ساندکلاد جایگزین می‌گیره؛ برای رفع کامل، فایل `cookies.txt` یه اکانت یوتیوب رو در `YTDLP_COOKIES` بده.
- **کش:** فایل‌های دانلودی ۴۸ ساعت و فایل‌های موقت ۱ ساعت نگه داشته میشن.
- **کپی‌رایت:** مسئولیت محتوایی که کاربران دانلود می‌کنن با صاحب رباته؛ قوانین منابع و کشور خودت رو رعایت کن.
