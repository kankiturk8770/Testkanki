# Kanki Music — ربات موزیک روی Telegram Serverless

ربات تلگرام + مینی‌اپ برای پیدا کردن، تشخیص دادن، دانلود و ویرایش آهنگ، که کامل روی **[Telegram Serverless](https://core.telegram.org/bots/serverless)** (بخش Serverless در BotFather) اجرا میشه. سرور، Docker و هاست جدا لازم نیست.

## ساختار پروژه (همون چیزی که پنل Serverless نشون میده)

| بخش در BotFather | پوشه | چی داره |
|---|---|---|
| **Handlers** | `tgcloud/handlers/` | `message.js` (پیام، ویس، ویدیو، لینک، جستجو)، `callback_query.js` (دکمه‌ها)، `channel_post.js` (کانال ذخیره) |
| **Endpoints** | `tgcloud/endpoints/` | توابعی که مینی‌اپ صدا می‌زنه: `search`، `audioChunk`، `recognize`، `uploadEdit`، `playlist`، `library`، `history`، … |
| **Library** | `tgcloud/lib/` | `sources.js` (یوتیوب/ساندکلاد)، `recognize.js` (تشخیص آهنگ)، `deliver.js`، `store.js` (دیتابیس)، `ui.js`، `util.js` |
| **Database** | `tgcloud/schema.js` | کاربرها، آهنگ‌ها، تاریخچه، پلی‌لیست، لایک، کش فایل، تنظیمات |
| **Mini App Files** | `webapp/` | پلیر، کتابخانه، تاریخچه، ویرایشگر، «گوش بده» |

## امکانات

**در چت**
- 🔎 جستجو با اسم آهنگ، خواننده یا تیکه‌ای از متن، هم‌زمان در **یوتیوب و ساندکلاد** (آهنگ محلی، ریمیکس، کاور و لایو هم پیدا میشه).
- 🎙 **تشخیص آهنگ** از ویس، فایل صوتی، ویدیو، ویدیو مسیج و لینک. اگه کپشن ویس «زمزمه» باشه، مستقیم میره سراغ تشخیص زمزمه.
- 🎧 دانلود آهنگ (128/192/320) یا ویس، 🎬 ویدیو (360p تا 1080p).
- 💬 دستور با متن: «آهنگشو بفرست»، «ویدیوشو بفرست»، «ریمیکساش»، «برش ۰:۳۰ تا ۱:۰۰»، «آهنگ بارون رو بفرست».
- ✂️ زیر هر آهنگ: برش، رینگتون، اسلو + ریورب، تند، باس، 8D، بی‌کلام. این دکمه‌ها ویرایشگر مینی‌اپ رو باز می‌کنن.
- 🔁 ریمیکس‌ها، ❤️ لایک، ➕ پلی‌لیست. فایلی که یه بار فرستاده شده دفعه بعد آنی میاد (کش `file_id`).

**در مینی‌اپ**
- 🎵 پلیر کامل: کشیدن نوار، کشیدن کاور به چپ و راست برای قبلی/بعدی، تکرار همه/یکی، تصادفی، صف، سرعت پخش، ±۱۰ ثانیه، کنترل از صفحه قفل.
- ✂️ **ویرایشگر**: انتخاب بازه با اسلایدر یا «از همین لحظه»، **گوش دادن زنده** به همون تیکه با افکت انتخابی، فید، و ساخت mp3 یا ویس که تو چت فرستاده میشه.
- 🎙 **گوش بده**: ضبط ۱۲ ثانیه و تشخیص، با حالت «خودم می‌خونم/زمزمه».
- 📚 **🌟 منتخب تو** (پلی‌لیست خودکار از روی پخش، دانلود، ویرایش و لایک با کم شدن وزن کارهای قدیمی)، لایک‌ها، پلی‌لیست‌های شخصی.
- 🕘 **تاریخچه کامل** جدا از پلی‌لیست‌ها، روز به روز، با فیلتر.

## چرا بعضی چیزها این‌طوری ساخته شده (محدودیت‌های Serverless)

Serverless فقط جاوااسکریپت ساده اجرا می‌کنه: **ffmpeg، yt-dlp، فایل‌سیستم و پکیج npm نداره**، و هر `fetch` حداکثر **۳۰ مگ** جواب می‌گیره.

- **ویرایش صدا** (برش، افکت، رینگتون) برای همین **تو مینی‌اپ و روی گوشی کاربر** انجام میشه (Web Audio + انکودر mp3). نتیجه برای ربات آپلود میشه و ربات تو چت می‌فرسته.
- **ساندکلاد** مستقیم دانلود میشه (AAC 160k، زیر ۲ ثانیه). آهنگ‌های DRM‌دار رد میشن و جایگزین پیدا میشه.
- **یوتیوب** (تست‌شده روی سرور تلگرام): جستجو کار می‌کنه. ولی بدون «PO token» فقط حدود ۱ مگ اول هر فایل رو به سرور میده. پس صدای آهنگ‌های یوتیوب خودکار از ساندکلاد گرفته میشه. **ویدیو** و **لینک اینستا/تیک‌تاک** سرویس دانلود [cobalt](https://github.com/imputnet/cobalt) لازم دارن (`/set cobalt_url`). یه muxer کوچیک (`lib/mp4mux.js`) هم هست که ویدیو و صدای جدای یوتیوب رو بدون ffmpeg یکی می‌کنه؛ روی یه ویدیوی واقعی یوتیوب تست شده.
- **Shazam رایگانه و کلید نمی‌خواد.** اثرانگشت آهنگ تو مینی‌اپ (روی گوشی کاربر) با `shazamio-core` ساخته میشه، چون WebAssembly تو Serverless اجرا نمیشه. اندپوینت `shazam` فقط از API شازم می‌پرسه. ویس یا ویدیویی که تو چت فرستاده میشه دکمه‌ی «🔍 تشخیص با Shazam» می‌گیره که مینی‌اپ رو باز می‌کنه و خودکار تشخیص میده.
- AudD، ACRCloud و Whisper اختیاری‌ان: برای تشخیص مستقیم تو چت، **زمزمه** و **آوازی که خود کاربر می‌خونه**.
- محدودیت‌های تلگرام: آپلود تا ۵۰ مگ، دانلود فایل کاربر تا ۲۰ مگ.

## راه‌اندازی

### ۱. روشن کردن Serverless
`@BotFather` ← ربات ← **Serverless** ← روشن (همون صفحه‌ای که اسکرین‌شاتش رو فرستادی).

### ۲. آپلود کد (با کامپیوتر — راحت‌ترین راه)
```bash
git clone <این ریپو> && cd Testkanki/music-bot
npm install
npx tgcloud login      # توکن: BotFather ← Serverless ← CLI Access
npx tgcloud push       # آپلود handlers، endpoints، library، schema و مینی‌اپ
npx tgcloud migrate    # ساخت جدول‌های دیتابیس (تأیید کن)
```
`push` آدرس مینی‌اپ رو چاپ می‌کنه: `https://app<id>.tgcloud.ai/`

**فقط با گوشی؟** همه‌ی این فایل‌ها رو میشه تو همون پنل BotFather ساخت: هر فایل `tgcloud/handlers/*` رو در **Handlers**، `tgcloud/endpoints/*` رو در **Endpoints**، `tgcloud/lib/*` رو در **Library**، `tgcloud/schema.js` رو در **Database** (بعد Apply)، و `webapp/*` رو در **Mini App Files** کپی کن.

### ۳. وصل کردن مینی‌اپ
- در BotFather: ربات ← Bot Settings ← Configure Mini App ← آدرس `https://app<id>.tgcloud.ai/` (اختیاری ولی پیشنهادی، برای دکمه منو).
- تو چت ربات:
  1. `/admin` — اولین نفری که بزنه ادمین میشه
  2. `/set webapp_url https://app<id>.tgcloud.ai/`

### ۴. کلیدها (با `/set` تو چت؛ ربات پیام حاوی کلید رو پاک می‌کنه)

| دستور | برای چی | از کجا |
|---|---|---|
| `/set audd_token …` | تشخیص مستقیم تو چت (Shazam بدون کلید هم کار می‌کنه) | audd.io |
| `/set acr_host …` و `acr_key` و `acr_secret` | تشخیص؛ ریمیکس و کاور | console.acrcloud.com |
| `/set acr_hum_key …` و `acr_hum_secret` | تشخیص **زمزمه/آواز** | ACRCloud، پروژه Humming |
| `/set stt_key …` | تبدیل آواز کاربر به متن (Whisper) | console.groq.com (رایگان) |
| `/set genius_token …` | پیدا کردن آهنگ از روی متن | genius.com/api-clients |
| `/set cobalt_url …` و `cobalt_key` | یوتیوب ۳۲۰، ویدیو HD، اینستا/تیک‌تاک | یه نمونه cobalt |

دستورهای دیگه: `/settings` (وضعیت تنظیمات) و `/unset نام` (پاک کردن یه تنظیم).

### ۵. کانال ذخیره (پیشنهادی)
پلیر مینی‌اپ باید فایل هر آهنگ رو یه بار تو تلگرام آپلود کنه. بدون کانال ذخیره، این فایل‌ها تو چت خود کاربر میان.
1. یه کانال خصوصی بساز و ربات رو ادمینش کن.
2. تو کانال بنویس `/storage`.
3. تو چت ربات «تأیید» رو بزن.
